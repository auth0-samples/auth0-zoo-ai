# Zoo AI: Managing a Zoo using LLM's

The Zoo AI management platform consists of two projects: API and Agent. Both projects have a similar stack to make the platform as simple as possible for demonstration purposes.

Both projects will also use the same Poetry environment to simplify set up. Poetry is completely optional but makes dependency management easier. You can check the Poetry website for more details.

There are two available versions, with the same issues in both:

- [LangChain Python](py-langchain/README.md)
- [LlamaIndex Python](py-llamaindex/README.md)

The LangChain version is algo theme of a series of article posts:

* [Secure LangChain Tool Calling with Python, FastAPI, and Auth0 Authentication](https://auth0.com/blog/first-party-tool-calling-python-fastapi-auth0-langchain/) 
* [Secure Third-Party Tool Calling: A Guide to LangGraph Tool Calling and Secure AI Integration in Python](https://auth0.com/blog/secure-third-party-tool-calling-python-fastapi-auth0-langchain-langgraph/)
* [Implementing Asynchronous Human-in-the-Loop Authorization in Python with LangGraph and Auth0](https://auth0.com/blog/async-ciba-python-langgraph-auth0/)
